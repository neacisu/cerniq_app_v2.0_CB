# Continuitate v1 → v2 (bridge)

## Stance implicit

**v2 = greenfield.** Bridge-ul către v1 este **opțional** și necesită scope explicit.

## Dacă se cere bridge

- Export date v1 (format documentat), import în scheme `business.*`.
- Criterii go/no-go: completitudine mapare, test migrare pe staging, semn-off business.

## Out of scope

- Dacă nu se aprobă: ADR **Excluded** cu motiv (timp, calitate date v1, etc.).

## stacks-01

- Fără presupuneri despre schema v1 fără audit CMDB.
